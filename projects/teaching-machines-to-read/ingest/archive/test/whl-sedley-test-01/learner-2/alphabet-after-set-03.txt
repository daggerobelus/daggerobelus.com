Carries forward set-01 and set-02 snapshots; records set-3 additions/revisions.

=== EXTENSIONS / CONFIRMATIONS ===

Roman numerals — by set 3 the recipe index reaches XLI. Confirmed forms:
  V=V, X=X, L=L, I/j (final j) for ones. "iij"=3, "iiij" not seen; "24","30"
  appear as Arabic. The numeral line sits centered under each title.

apostrophe-s — the scribe DOES use the possessive apostrophe: "bramble's
  leaves","Bramble's leaves","St Anthony's fire","sheeps"(no apos here),
  "Sheep's"(set1 conv). Preserve exactly as written (some have it, some don't).

clipped pronoun "em" = them: "mixe em","stamp em" (p.016). New, confirmed.

"peys" = pea (size-of-a-pea), recurring p.016 spelling. settled habit.

"Plast" = plaister (cut form) p.016; "oyntmt"=ointment; "funda~t"=fundament;
  "-mt" / "~t" superscript = -ment. Confirmed contraction family.

pious formulas: "(by Gods grace)","by the Grace of God","(say God)" — recurring
  set-end/clause tags. Read literally.

=== LETTERFORM NOTES (final) ===
- long-s vs f: settled. f always has the full crossbar; long-s a half-tick or
  none. "ffirst"=capital F (double long-form).
- w initial in "wine","water","white","whitewine","Wrest","worme" — large
  looped w, sometimes mistakable for "vu"/"in" at speed.
- the scribe's "sore" vs an apparent "whore": the s can be a tall long-s that
  with the following h+o reads deceptively like "wh-"; in face/skin recipes
  the word is "sore" (see revision log p.014).
- proper/ingredient names remain the dominant flag source across all 3 sets;
  general lowercase alphabet is stable and was calibrated correctly at set 1.

=== STABILITY ===
No alphabet drift across sets 1-3. The same letterforms calibrated at set 1
read sets 2 and 3 without revision to the core a-z. Remaining uncertainty is
concentrated in: (a) idiosyncratic herb/drug names, (b) Latin pharmacopeia
terms, (c) a few muddy clauses where the original itself is hurried.
