# Blind Transcription Test — Instructions

You are performing a **blind transcription** of early modern English manuscript pages. You have access to:

- **5 manuscript images** (JPG files in this folder)
- **A paleography guide** (`paleography-guide.md`) that describes secretary hand letterforms, common abbreviations, and editorial conventions

You do **NOT** have access to any reference transcriptions or previous test results. This is intentional — your transcription must be based solely on what you can read in the manuscript images, guided by the paleography guide.

## Your Task

For each manuscript image in this folder:

1. Read the paleography guide first (if you haven't already)
2. Open the manuscript image
3. Produce a **semi-diplomatic transcription** following the Folger editorial conventions described in the guide
4. Include confidence flags where readings are uncertain
5. Save each transcription as a separate text file named `[manuscript]-transcription.txt`

## Output Format

For each page, produce:
- A header with the manuscript name and page number (from the filename)
- The transcription, preserving original spelling, punctuation, capitalization, and lineation
- A "Confidence Notes" section listing any flagged readings

## Important Reminders

- Transcribe what you SEE, not what you think it should say
- Preserve original spelling — do not modernize
- Preserve original punctuation and capitalization
- Expand abbreviations with supplied letters in italics (use *italics* in markdown)
- Flag uncertain readings with [word?] notation
- Do NOT guess at illegible text — use [...] notation
