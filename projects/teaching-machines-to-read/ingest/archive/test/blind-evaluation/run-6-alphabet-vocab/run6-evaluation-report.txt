METHOD
--------------------------------------------------------------------------------
Run 6 uses the alphabet-first transcription method with an added
vocabulary verification step. The transcription agent:
  1. Built a hand-specific alphabet from the manuscript image
  2. Transcribed the page using that alphabet + paleography guide
  3. Verified readings against a vocabulary reference of attested
     early modern recipe terms

CER = (Substitutions + Insertions + Deletions) / Total Reference Characters
Computed using character-level Levenshtein edit distance.

TWO CER METRICS ARE REPORTED:

  1. FULL CER: Standard CER comparing blind text (with [...] removed)
     against the full reference. Penalizes for unread sections.

  2. ATTEMPTED CER: CER computed only on text the agent attempted to read.
     [...] markers are aligned with reference words and those sections
     are excluded from both sides. This measures accuracy of what was
     actually transcribed, per the evaluation instructions.

For manuscripts with few/no [...] markers, these are nearly identical.
For manuscripts with heavy [...] usage, they differ substantially.

Normalization applied to blind text:
  - Headers, confidence notes, and metadata stripped
  - Decorative dot patterns stripped
  - Confidence markers [word?] -> word
  - Italic markers *letters* -> letters
  - Section labels stripped ([LEFT PAGE - VERSO], etc.)
  - [...] illegibility markers handled via alignment exclusion

Normalization applied to reference text:
  - Source metadata header stripped
  - Editorial brackets stripped ([er] -> er, etc.)
  - Superscript markers ^ stripped
  - Page numbers in braces {6} stripped
  - Whitespace normalized

================================================================================
KEY FINDINGS
================================================================================

1. HENSLOW (easiest): New best at 3.80% -- vocabulary verification helped.
   This is close to Transkribus Egerton quality (~3% CER).

2. BULKELEY (moderate): New best at 16.21% -- improved over all previous runs.
   Vocabulary verification reduced letterform errors.

3. SEDLEY (moderate): Roughly flat at ~17% -- no meaningful change.
   Main errors are content-level misreadings, not letterform issues.

4. BRUMWICH & JANE JACKSON (hardest): The alphabet-first + vocab method made
   the agent MORE CONSERVATIVE -- it marked far more text as illegible rather
   than guessing. This is arguably better scholarly practice (honest about
   what cannot be read) but produces worse full CER scores because the
   denominator (reference length) stays the same while less text is attempted.

5. OVERALL PATTERN: Vocabulary verification improves accuracy on legible
   manuscripts (where letterforms can be traced and checked against known
   vocabulary). For difficult manuscripts, it increases conservatism rather
   than accuracy -- the agent recognizes when its readings don't match
   attested vocabulary and marks them illegible rather than forcing a reading.

6. THE ACCURACY-COVERAGE TRADEOFF: There is a fundamental tension between
   accuracy (how correct is what was transcribed) and coverage (how much of
   the page was transcribed). Run 4 achieved better coverage on Brumwich by
   attempting to read more, but its accuracy on those readings is uncertain.
   Run 6 is more honest about uncertainty but transcribes less.
