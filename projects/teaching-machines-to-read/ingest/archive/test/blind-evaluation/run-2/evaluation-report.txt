BLIND TRANSCRIPTION EVALUATION REPORT
Run 2 — Updated Paleography Guide
Date: 2026-02-27
======================================

This report evaluates blind transcriptions produced by a separate agent
(who had only manuscript images and a paleography guide) against reference
transcriptions from FromThePage. The evaluator does NOT have access to the
original manuscript images — this is a text-against-text comparison only.

CER (Character Error Rate) is the primary metric:
  CER = (Substitutions + Insertions + Deletions) / Total Reference Characters

NOTE ON METHODOLOGY: CER values in this report are APPROXIMATE. They were
computed by manual character-by-character comparison without the ability to
run automated Levenshtein distance calculation. The values are estimates
based on careful enumeration of all differences but may be off by a few
percentage points. The relative ordering and general magnitude of errors
are reliable.

Note on cleaning: Before comparison, blind transcriptions were stripped of
headers, confidence notes, page markers ([Left page], [Right page]), and
metadata. Confidence markers [word?] were reduced to the underlying reading
(e.g., [Canker?] -> Canker). Illegibility markers [...] were treated as
empty strings (omissions). Italic expansion markers (*i*, *ou*, etc.) were
stripped. The decorative dots (......) in Henslow were preserved since they
appear to represent line fillers in the original.

Reference transcriptions were stripped of source headers and metadata.
Editorial marks like [seised], ^eales, {page numbers} were cleaned.

This manuscript is a total failure. The blind transcription does not

THE ENTIRE TRANSCRIPTION IS HALLUCINATED.

mostly illegible text with different recipe titles and different content.

The few structural elements that superficially match (e.g., both have
recipe headings starting with "ffor") are coincidental — early modern
recipe books commonly use this format.

Possible explanations:
  a) The agent was given a different page image than page 20
  b) The agent hallucinated plausible recipe text instead of reading
  c) The image was too low resolution for the agent to read

Given that the reference shows page 20 as containing clearly legible,
well-formed recipes, explanation (b) — hallucination — is the most
likely unless the wrong image was provided.

   The agent produced plausible-sounding recipe text that does not
   correspond to what is actually on the page. This is the same
   fundamental problem reported in Run 1.

   For these two manuscripts, CER approaches ~95% — meaning the
   transcription is essentially random text relative to the reference.

2. THE UPDATED GUIDE DID NOT FIX HALLUCINATION

   The Run 1 hallucination problem persists in Run 2 unchanged. Jane
   Jackson (~95% CER) and Brumwich (~93% CER) are catastrophic
   failures in both runs. The paleography guide update appears to have
   had no effect on these difficult manuscripts.

3. MODERATE MANUSCRIPTS SHOW MIXED RESULTS

   For the three manuscripts where the agent read the correct page:
   - Sedley: WORSE than Run 1 (~21% vs ~15.8%)
   - Bulkeley: Somewhat improved (~18% vs ~22.8%)
   - Henslow: Approximately the same (~12% vs ~11.3%)

   Even the best result (Henslow at ~12%) is more than double the
   5% usability threshold and approximately 4x the Transkribus Egerton
   benchmark of ~3%.

4. SYSTEMATIC ERROR PATTERNS (in manuscripts that were not hallucinated)

   a) DOUBLED CONSONANTS: The blind transcription systematically drops
      doubled final consonants (put/putt, it/itt, knit/knitt). This
      is a consistent pattern in Henslow and appears elsewhere.

   b) MINIM CONFUSION: Letters formed by vertical strokes (i, n, m, u)
      are frequently confused: Caunterberries/Cannterberries,
      Boorrage/Buorrage, etc.

   c) CATASTROPHIC PHRASE-LEVEL MISREADINGS (Sedley especially):
      - "on a bole of boxe" should be "with a bolt of Iron"
      - "fassionably enough" should be "t'is boyled enough"
      - "dyppes thicker" should be "dipp your cloathes"
      - "seemes aportment" should be "comes upermost"
      These are not single-letter errors but wholesale misreadings
      of entire phrases that produce nonsensical text.

   d) LETTERFORM MISREADINGS (Bulkeley):
      - "cause" for "haue" (multiple times)
      - "sreste" for "sicke"
      - "Lauder" for "danger"
      - "liuors" for "divers"
      These suggest the agent is pattern-matching to plausible words
      rather than tracing individual letterforms.

   e) RECIPE TITLE/STRUCTURE ERRORS (Sedley):
      - "Pills for the Gall" should be "Pills for the head"
      - "A Third Cordiall for Mistres Owell" should be
        "A Good Cordiall For A woman"
      Getting recipe titles wrong undermines the structural value of
      the transcription even where body text is partially correct.

5. ACCURACY DOES NOT MEET ANY STANDARD BENCHMARK

   No manuscript achieves even the 5% CER threshold for "usable"
   transcription. The best result (Henslow at ~12%) is approximately
   4x worse than the Transkribus Egerton model benchmark (~3% CER)
   and 12x worse than the "very good" threshold (<1% CER).

   The overall CER of ~67% across all five manuscripts indicates
   the pipeline is not viable for transcription purposes.

6. ILLEGIBILITY MARKING VS. HALLUCINATION

   When the agent cannot read text, it has two failure modes:
   a) Mark it as [...] (honest acknowledgment of illegibility)
   b) Produce a plausible but wrong reading (hallucination)

   For Jane Jackson and Brumwich, the agent does both — extensive [...]
   markers alongside hallucinated readings. For Sedley and Bulkeley,
   the agent rarely uses [...] but produces many wrong readings,
   suggesting overconfidence in incorrect readings.

   The [...] marking approach (as seen in the difficult parts of Jane
   Jackson and Brumwich) is actually more useful than confident wrong
   readings, because it at least signals where human review is needed.
   The problem is that the agent applies [...] to pages it cannot read
   at all while producing false-confident readings on pages it can
   partially read.

======================================================================
RECOMMENDATIONS
======================================================================

1. The hallucination problem is fundamental and cannot be solved by
   guide improvements alone. The agent needs either:
   a) A verification step that checks transcription against the image
   b) A different approach for difficult manuscripts (e.g., the
      fine-tuned TrOCR pipeline described in the project plan)
   c) Higher-resolution images

2. For the three manuscripts that were read correctly but inaccurately
   (Sedley, Bulkeley, Henslow), the errors suggest the agent is
   "reading" at a word-level pattern-matching level rather than tracing
   individual letterforms. This produces plausible but incorrect text.

3. The doubled-consonant problem suggests the agent has a systematic
   bias toward modern spelling conventions (single consonants) over
   early modern conventions (doubled consonants). This could potentially
   be addressed through guide instructions.

4. None of these results are usable for scholarly purposes without
   extensive human correction. The pipeline in its current form
   cannot replace or meaningfully assist human paleographic transcription.
