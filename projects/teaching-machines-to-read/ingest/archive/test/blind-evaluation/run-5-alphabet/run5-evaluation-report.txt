OVERVIEW
--------
This is the fifth run of the blind transcription evaluation. Run 5
uses the alphabet-first method with a two-agent workflow:
  - First-pass agent: builds letter chart + transcribes
  - Review agent (for Brumwich and Jane Jackson): re-examines flagged
    words using the alphabet chart

Five manuscripts were tested, ranging from clear hands (Henslow) to
severely damaged pages (Jane Jackson).

CER (Character Error Rate) is computed using character-level Levenshtein
edit distance: CER = (Substitutions + Insertions + Deletions) / Total
Reference Characters.

WHAT CHANGED FROM RUN 4 TO RUN 5
========================================================================

IMPROVEMENTS:
- Jane Jackson fragment-aligned CER improved dramatically:
  77.41% (Run 4) -> 46.85% (Run 5). This suggests the review agent
  helped resolve false illegibility flags and improved some readings.
  However, the agent still cannot read most of this manuscript.

REGRESSIONS:
- Henslow: 4.96% -> 5.38% (minor regression, within noise)
- Sedley: 15.13% -> 16.55% (minor regression)
- Bulkeley: 18.70% -> 20.90% (regression)
- Brumwich: 9.30% -> 50.62% (apparent large regression, but likely
  reflects different measurement methodology rather than worse reading)

OVERALL ASSESSMENT:
Run 5 shows no meaningful improvement over Run 4 for the three
manuscripts the agent can partially read (Henslow, Sedley, Bulkeley).
The alphabet-first + review-agent approach does help with the most
difficult manuscripts (Jane Jackson improved), but the fundamental
limitation remains: the agent cannot read dense secretary hand at
this image resolution.

The benchmark comparison tells the story:
  - Best existing HTR (Transkribus Egerton): ~3% CER
  - Run 5 best result (Henslow): 5.38% CER
  - Run 5 average (readable MSS only): ~14.3% CER

For the clear-hand manuscripts, we are within 2x of the Transkribus
benchmark. For compact hands, we are 5-7x worse. For damaged or
very difficult manuscripts, the approach does not work.

KEY ERROR PATTERNS ACROSS ALL MANUSCRIPTS:
1. Letterform misreading remains the dominant error type (~60% of errors)
2. Hallucination of recipe titles and proper nouns (~15%)
3. u/v and i/y convention inconsistency (~10%)
4. Punctuation omission (~5%)
5. Double-letter errors in both directions (~5%)
6. Terminal 'e' addition/omission (~5%)

RECOMMENDATIONS FOR RUN 6:
1. Focus on Henslow-type manuscripts where CER is approaching usable
2. For Sedley/Bulkeley, try higher-resolution images
3. For Brumwich/Jane Jackson, these may be beyond current capability
   and should await the TrOCR fine-tuning approach
4. The review agent helps with flag resolution but does not improve
   fundamental reading accuracy — the bottleneck is letterform
   recognition, not confidence calibration
