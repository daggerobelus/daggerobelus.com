TRIAGE ASSESSMENT
=================
Factor scores (0=None,1=Minor,2=Moderate,3=Severe):

- Physical damage (water, mold, tears, foxing): 1
    Minor foxing/staining at page edges; text area largely clean.
- Scan quality (x2): 1 -> 2
    Single page per image, adequate resolution, slightly soft focus.
- Hand density (x2): 1 -> 2
    Generously spaced lines and words; headings set off.
- Multiple hands: 0
    Single scribe throughout.
- Ink quality: 1
    Mostly clear; some show-through and mild fading at line-ends.
- Hand quality: 1
    Well-formed display/secretary hand with decorative flourishes;
    generally legible.

TOTAL: 1 + 2 + 2 + 0 + 1 + 1 = 7

PATH CHOSEN: Standard Path (0-7). Score is at the top of the range,
so transcription proceeds carefully with attention to flourishes and
line-end fading.
