METHOD
--------------------------------------------------------------------------------
Run 8 uses a triple-pass consensus approach inspired by EMROC triple-keying:
  1. Three independent agents each transcribed all 5 manuscripts using the
     alphabet-first method (Run 4 style — NO vocabulary list)
  2. A fourth reconciliation agent merged the three passes into a consensus
     reading using majority rule
  3. Vocabulary verification was applied ONLY to the final consensus

This combines Run 4's confident reading (no vocab distraction during
transcription) with Run 6's vocab verification (on a strong consensus base).

CER = (Substitutions + Insertions + Deletions) / Total Reference Characters

TWO CER METRICS ARE REPORTED:
  1. FULL CER: vs entire reference, penalizes for unread sections
  2. ATTEMPTED CER: only on text actually transcribed
